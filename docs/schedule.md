## 운영 규칙

- **정기 회의**: 지난주 결과, 이번 주 목표, 막힌 점. 회의록은 학과 양식(hwp)으로 작성해 팀장이 보관한다 (2차 10/21, 3차 11/18)
- 작업은 `feat/<영역>-<내용>` 또는 `fix/…` 브랜치로 올린다 → 팀장이 검토·테스트 후 `main` 에 merge 하고 개발일지에 기록
- 인터페이스(Detector 반환 형식, SQLite 스키마)를 바꿀 때는 PR 설명에 영향 받는 팀원을 명시
- Slack Webhook URL 등 비밀값은 `.env` 에만 (커밋 금지)
