## 2026-11-23 · 대시보드 KST 표시, `make replay` 기본 속도 (옥상민)

점검 때 남겨 둔 작은 개선 두 가지와 화면 확인 중 찾은 문제 하나를 고쳤다.

- **대시보드 시각 → KST:** 표(최근 추론 윈도우·세션 상세·알림 이력)와 CSV 다운로드가 UTC(예: 05:46)로 보여 Slack 메시지(KST)와 9시간 어긋났다
  → 보여 주기 직전에만 KST 로 바꾸는 `data.to_kst` 추가. 조회 기간 필터 계산은 그대로 UTC
- **점수 그래프 축:** `st.line_chart` 는 축을 `02:52` 처럼 12시간제로 그려 오전·오후를 알 수 없었다 → Altair 로 그려 24시간제(`14:52:08`) KST 로 고정
- **모델 선택 초기화 (화면 확인 중 발견):** 데이터 소스를 SQLite → 데모로 바꾸면 이전에 고른 `autoencoder` 가 남아 데모 모델이 선택되지 않고 지표가 모두 0 이 됐다 → 모델 선택 상태를 데이터 소스마다 따로 둠
- **`make replay` 기본 속도:** 초당 100줄 → 1000줄 (`start.sh` 와 같음). 100 이면 test 전체(약 223만 줄) 재생에 6시간 넘게 걸렸다
- 확인: 테스트 65개 통과 (`to_kst` 테스트 추가), 브라우저에서 기준 시각·표·그래프 축·알림 이력이 모두 KST 로 일치, 소스 전환 후 모델 자동 선택
