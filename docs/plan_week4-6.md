## 목표

- 같은 데이터 분할에서 Autoencoder와 DeepLog를 학습·평가
- 최종 비교표: Rule-Based / 통계 빈도 / Autoencoder / DeepLog 의 P·R·F1 + 추론 지연 + 모델 크기
- 1차 목표 F1 ≥ 0.85, **실질 목표는 통계 빈도 베이스라인 0.887 초과** (참고: DeepLog 논문 HDFS F1 ≈ 0.96)

## 공통 원칙

1. **test는 마지막에 단 1회 평가.** 모든 튜닝은 val로만 하고, test 결과를 보고 설정을 바꾸지 않는다.
2. **세션(Block) 단위 판정.** 세션 점수 = 윈도우 점수의 최댓값. 윈도우 하나라도 이상이면 세션 이상.
3. **UNK 즉시 이상.** 학습(정상)에 없던 이벤트가 나오면 바로 이상으로 판정한다. 이상 세션에만 나오는 이벤트가 33종이고, 이것만으로 이상의 약 23%를 오탐 0건으로 잡는다.
4. **중복 윈도우 압축.** 정상 학습 윈도우 약 650만 개를 고유 윈도우 + 빈도 가중치로 줄여 M2 로컬에서 학습한다.
5. 결과는 `results/<model>.json` 으로 베이스라인과 같은 형식으로 저장한다.
